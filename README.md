# ATELIÊ — Modelo de portfólio fotográfico 01

Modelo demonstrativo de portfólio para a **Guará Agency**, com identidade fictícia “Ateliê”.

## Referência e atribuição
Conceito de interface inspirado no projeto open source [ECarry/photography-website](https://github.com/ECarry/photography-website) (Sera, licença MIT). O projeto original é uma aplicação Next.js 16 com PostgreSQL, Better Auth, Mapbox e armazenamento S3. **Este repositório é uma adaptação estática independente**, feita para funcionar no GitHub Pages, sem backend, sem login e sem gerenciamento de mídia.

O código do site de demonstração foi reimplementado em HTML, CSS e JavaScript. A licença MIT e a autoria do projeto de referência são reconhecidas; o site demonstrativo não reproduz imagens privadas, dados de usuários ou o dashboard original.

## Funcionalidades
- Página editorial com hero e responsividade;
- Galeria assimétrica de fotografias;
- Filtros por paisagem, retratos, arquitetura e viagens;
- Lightbox com navegação por teclado e controles acessíveis;
- Coleções por destino;
- Seção sobre e contato comercial;
- Tema claro/escuro, animações com preferência por movimento reduzido;
- Arquivo único `index.html` para publicação direta.

## Personalização
Editar `index.html`: nome da marca, títulos, textos, fotografias em `photographs` e links para contato. As fotografias carregam de URLs públicas do Unsplash e são apenas ilustrativas; substitua por imagens do cliente com os direitos de uso confirmados. Dados, marca e coleções são fictícios.

## Publicação
O projeto não exige build. Para habilitar o GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. URL esperada: https://guaraagency-julio.github.io/modelo-portifolio-1/

## Limites
Por ser estático, este modelo **não** inclui painel administrativo, upload de imagens, banco de dados, Mapbox ou blog dinâmico. Estas funcionalidades exigiriam serviços adicionais e hospedagem apropriada.
